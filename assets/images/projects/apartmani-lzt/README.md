# Project image folder

Duplicate this `_template` folder and rename it to the same value used in the project's `id`.

Recommended files:

- `thumbnail.webp` — project cards, usually 1600 × 1200 px
- `hero.webp` — case-study hero, usually 2400 px wide
- `social.webp` — Open Graph sharing image, ideally 1200 × 630 px
- `01.webp`, `02.webp`, `03.webp` — gallery images, usually 2000–2400 px wide

Use lowercase filenames without spaces. WebP is recommended, but JPEG, PNG and SVG also work.

The folder is only a convention: every actual path is still declared explicitly in `data/projects.json`.
